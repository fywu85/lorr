Declared before generating seeds 50007/50008 or observing their solver results.
Freeze source **5f81613**, build-v65, planner seed 3: first-step K4608, then
K5760/B12, two-branch screening with one-quarter retention, four generations,
eight elite parents and eight persistent vectors. Future blend is zero;
ranking cache capacity 512 and the exact kinematic mask are enabled. The
manifest pins every environment setting and both executable hashes. The
selected configuration completed 3,770 tasks in both four-core placement
controls, with zero errors/timeouts and maximum step latency under 846ms. No later
setup optimization, planner seed or experiment may replace this candidate.

Generated field 15, one flip with seed 5, contrast 2.4, and known-horizon
triage at 2000/scale1.5 remain explicit `--trick RANDOM-05` settings.
The unchanged archived map helper generates 800 unique starts and 100000 tasks
of 2–5 uniform stops, with a 1.5-agent reveal pool on random-32-32-20.
Record its hash, NumPy version, RNG offsets, generation timestamp and all
input hashes. These are new local task/start streams on the same map layout,
not the colleague's private instances.

For each input, run this candidate once and NMS4 twice. All six use four
physical EPYC9354 cores on research33/39, 2000 steps, a strict 1000ms entry
limit, 30000ms preprocessing and a 32 decimal GB process address-space guard.
Shared hosts are allowed; GRID reserves disjoint cores. Candidate OpenMP
binding stays false, exactly as specified in the four-core placement control;
its environment/affinity diagnostics remain enabled. NMS retains all combined
features and the documented constructor fix; only its worker constant differs
from NMS32.

Report every attempt and all errors/timeouts, latency and peak RSS. Use the
stronger valid NMS repetition per input for the ratio and aggregate. Do not
silently restart, change inputs/configuration, or omit a failed run. Failure
prevents a claim that the full predeclared comparison succeeded.

All inputs 50001–50008 remain excluded from tuning. Development can continue
on the archived input, but newer records do not replace this frozen candidate.
The V3 result (+25.46%) uses different validation inputs; changes between
campaign percentages are not paired causal estimates of this update.
